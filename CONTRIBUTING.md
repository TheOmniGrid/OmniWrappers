# Contributing

This is a documentation-only public repository. Helpful contributions include
documentation corrections, reproducible compatibility reports, accessibility
feedback, translations, and links to authoritative upstream information.

## Before opening an issue

- Select the real game executable, not a launcher or shortcut.
- Record the OmniVex product and version, game patch, executable architecture,
  Windows version, GPU, and driver.
- Roll back before testing a different wrapper plan.
- Remove account data, tokens, personal paths, copyrighted game files, and
  private crash dumps.

## Repository boundary

Do not submit source code, installer binaries, runtime DLLs, archives, payloads,
build scripts, certificates, keys, or private release evidence. This repository
accepts documentation, repository metadata, and approved visual assets only.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and email
`omnivex@theomnigrid.biz` instead of opening a public issue.
