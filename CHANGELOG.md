# OmniWrappers 1.0.0

First unified consumer release of OmniDXVK, OmniDxWrapper, OmniVoodoo2 and
OmniVKD3D.

## Current final-candidate refresh — 25 August 2026

- Expanded the live selector and guided consumer UI to ten languages: English,
  German, Spanish, French, Romanian, Russian, Simplified Chinese, Japanese,
  Korean, and Turkish, with reviewed safety terminology and safe English fallback.
- Added OmniMatch, local graphics/Vulkan readiness, exact hash/version-only
  offline profiles, installation-health states, repair, safe upgrade, one
  previous known-good version, and explicit finish-or-restore recovery.
- Added the optional reversible 4 GB address-space path for eligible native x86
  games, isolated from wrapper deployment and protected by exact backup/hash checks.
- Moved long-running analysis and lifecycle work off the UI thread, removed
  perpetual idle animation clocks, and unified all consumer confirmations and
  secondary windows under the square OmniVex visual system.
- Current gates pass: consumer 17/17, smart flow 12/12, transaction/recovery
  5/5, 4 GB safety 16/16, localization 14/14, UI contract 10/10,
  documentation 4/4, and payload lock 22/22.

## Highlights

- Unified 1.0.0 installer identity across all four products.
- Automatic PE architecture and graphics-import analysis.
- Exact DLL-name planning with companion dependency expansion.
- Per-game backup, manifest, collision handling and rollback.
- Ten interface languages and readable localized hover/help flows.
- Consumer-only surface with developer/Wave functions excluded.
- Distinct vendor-coded icons and accessible Precision Hybrid visual system.
- OmniVoodoo2 changed to user-supplied, pinned official packages.
- Final-path canonicalization closes junction/symlink target aliases.
- Payload-lock verification covers all 22 embedded runtime/config inputs.
- Rollback input and memory use are bounded; verified updates parse exact signed bytes.

## Known limits

- OmniDxWrapper runtime is x86-only.
- OmniVKD3D is experimental on native Windows.
- Compatibility is game-, patch-, driver- and mod-specific.
- Production Authenticode signing is still required before public delivery.
